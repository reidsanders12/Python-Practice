## foodAPI.py

A lightweight command-line tool built in Python that queries the Open Food Facts API to instantly fetch product names, brands, and nutritional data using a product's barcode.

**Features**

- Rest API Integration: Connects directly to the Open Food Facts v2 API using custom headers

- Resilient Parsing: Safely handles sparse or incomplete crowdsourced database records with fallback keys (e.g., handling French and English product name keys)

- Error Handling: Gracefully manages network timeouts, HTTP errors, and missing product IDs
